How this dashboard works

cpu_metric and mem_metric come from psutil inside this pod's container — that's node-level usage, not aggregate cluster usage. The banner above fires when Flask's app.py sets a warning past 80%. If app.py also passes pod_name (try socket.gethostname()), you'll see it change here every time a different replica answers your request behind the Kubernetes Service — a quick way to watch load-balancing across pods in real time.

This page first tries fetch('/metrics') for smooth live updates, and falls back to a full page reload every 5s if that route doesn't exist yet. Add a small JSON route returning the same three fields to upgrade it.
